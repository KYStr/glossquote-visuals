<a id="perf-2-pass"></a>

## PERF-2　PASS

<a id="ui-2-pass"></a>

## UI-2　PASS

核對可見焦點、表單與恢復狀態。十份版型共量 90 個主要操作熱區，均至少 44 × 44 CSS px。一般文字的純色對比最低為 6.45:1，合成文字另外以原圖取樣。觸控可完成選擇、重播及下載。

型錄列出蜜柑、覆盆莓、白芭樂的口味、成分、100 mL 單杯與六杯禮盒，中文和英文皆可確認成分、過敏原及保存條件。

<a id="biz-2-pass"></a>

空盒和未滿六杯時下載受限，滿盒後第七杯被拒；移除再配齊，匯出的三款杯數為 3、1、2，共 600 mL。

<a id="fall-1-pass"></a>

## FALL-1　PASS

無 JS、減少動態及 GPU 不可用時，首屏保留模具輪廓、果色、盤面與配盒入口。減少動態時預設靜止；GPU 失敗時仍可選六杯並取得配盒單。

<a id="fall-2-pass"></a>

## FALL-2　PASS

裝置遺失後恢復至可用狀態。快速暫停、續播、實際離頁再回返均能再取得畫布；商業內容一直可讀，沒有遮住頁面的空白層。

<a id="ship-1-pass"></a>

## SHIP-1　PASS

候選四組隔離建置皆以 lockfile 安裝，check、單元測試與 build 通過。實際請求同源，無追蹤或 storage 副作用。兩語可互返，canonical、分享圖、畫廊連結與正式路徑相符。

<a id="silhouette-pass"></a>

## silhouette　PASS

縮至 160 px 仍看到圓頂果凍、盤沿與右側長匙。起點是一整顆果凍，末段匙碗與果凍分開，中間留有空隙。

<a id="finish-pass"></a>

## finish　PASS

檢查原尺寸果凍冠部的圓角、銀匙末端及盤口窄邊。離盤的小塊仍有清楚輪廓，和匙碗相接的位置沒有亮色外圈。

<a id="material-pass"></a>

## material　PASS

果凍的透光集中在圓頂薄邊與切面；銀匙的亮邊及瓷盤下的柔影分別交代金屬和重量。

<a id="narrative-pass"></a>

## narrative　PASS

銀匙靠近，按入圓頂邊緣，接著把一口橙色果凍托起。完成後停留，可察看盤上的凹面，再換一側挖。

<a id="continuity-pass"></a>

## continuity　PASS

沿匙碗追蹤入刀與抬起，接觸時有局部遮擋，分離後淺金色凹面留在原處；切點換側，凹面跟著改變。

<a id="fidelity-pass"></a>

## fidelity　PASS

即時畫面的琥珀橙與上窄下寬的模具對得上首圖和口味卡；禮盒裡用一致色碼標示三種口味，手機仍看得見匙碗。

## desktop 動態貼合

桌面首訪能見完整果凍、切入和托起。控制可檢視三種口味；暫停及換切點後的缺口與實際位置一致。

## mobile 動態貼合

手機畫框容納圓頂主體與匙碗；點選不同切點後可見兩側不同的取樣結果，互動影片涵蓋切入至停留。
