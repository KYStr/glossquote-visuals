# M03 夜航訊號版頭候選

依工作室的 M03 版頭 brief，為原創夜間電子音樂品牌重作主海報。保留 2026 年 11 月 21 日、北堤聲場、三段節目與選票流程。

## 形態與材質

- 離岸載波是以黃銅與深紫明暗呈現的寬窄雙帶，10 秒週期。盲區回聲是兩股不同相位、繞行較密的靛青帶，8 秒週期。晨線有三股向外展開的暖紅帶，12 秒週期。節目切換以同一組均勻參數在約 940 毫秒過渡，沿用一個裝置與 canvas。
- 公開 pinned Shaders 4.0.7 的 `defineShader`、`wgsl` 與 `registerShader` 提供自訂產生器。現有元件缺少帶切口的交錯表面與背面遮擋。此處以同一正交射線求出截面的前、後交點，再以纏繞角裁出帶面。高光、細紋及深淺跟著該表面，兩股微粒也沿著對應的節奏移動。共用 standalone 入口維持遙測關閉。 [Shaders 自訂元件文件](https://shaders.com/docs/guide/custom-shaders)
- 桌面文字和雕塑共享深底海報。較窄螢幕優先呈現品牌、活動性質、日期、場地及票種入口，再呈現完整雕塑。無 JavaScript、無 GPU 與減少動態模式使用本地靜態圖。靜態 WebP 以相同正交截面、色彩及打光計算固定姿勢後輸出，並用於分享圖。
- 暫停會凍結已呈現的 canvas，節目過渡的時鐘同時停止。續播時恢復運作。隱藏與移出畫面停幀，離頁釋放渲染器。

## 驗收證據

由原有 GitHub Actions 的 GitHub-hosted Windows Server 2025 runner 執行。以 `results.json` 的 `commit` 與 PR head 核對。以下檔案可在該次 run 的 `visual-candidate-<SHA>-Windows` 取得。

- `signal-desktop-*`、`signal-mobile-*` 含同一工作階段的自然時序 PNG。每個節目、每個尺寸皆保存 0/2/4/6/8 秒，較長的週期另保存至 10 或 12 秒。逐時 `-texture.png` 為原尺寸 GPU 紋理讀回。瀏覽器首屏與全頁另存。時間點為名目取樣，報告也記錄實際送出讀回要求與 GPU 提交影格的時間。
- `signal-transition-*` 記錄三段節目循環切換前、切換開始、350／700 毫秒與結束。以 Playwright 控制瀏覽器時鐘，先擷取原尺寸合成 PNG 再輸出 GPU 讀回。報告分別記錄邏輯時間與實際經過時間。自然週期取樣使用未快轉的時鐘。
- `signal-desktop-pause*`、`signal-mobile-pause*` 的可見舞台 PNG 進行原尺寸像素比對，容許極少量 WARP 合成捨入誤差，同時確認 canvas 保持可見、沒有額外的呈現幀，續播後像素再變化。
- 保留中英桌面與手機全頁、320 px／200% 與 768 px、無 JS／GPU、選票狀態及兩份實際下載的 `.txt`。
- 此測試環境使用 D3D11 WARP 軟體渲染。實體手機與人工讀屏仍待驗，獨立動態美術與評分待主責確認。
