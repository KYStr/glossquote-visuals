# V011 食刻 UMBRA DIAL

兩個 HTML 入口自帶完整片單、場地規格和手動排程方法。互動提案只用片名、總人數及穹頂規格，資料在頁內計算，下載是本地 UTF-8 TXT。示意首場 09:30，每兩場之間留 15 分鐘。每批 12 人起，試排上限三場，小型穹頂每場 24 人，大型每場 36 人。產生提案後可回表單改條件，下載內容會反映重算後的資料。

初次載入有 10 秒自動週期。GPU 時鐘 0.83 秒可見亮珠，1.04 秒日月中心對齊，細環維持到 2.25 秒後慢慢復圓。選擇初虧、食甚或復圓會切到對應食相，保留低頻日冕變化。暫停期間畫布保留當幀，續播時套用期間選取的新食相。低動態及無 GPU 時，三個控制改用同一套日、月幾何產出的靜態圖。

- `npm ci --ignore-scripts --no-audit --no-fund`、`npm run check`、`npm test` 已執行，既有測試 23 項通過。使用現有候選配置指定 V011 雙語入口完成 scoped build。將各頁資產及 GPU lazy chunk 同時計入，繁中 917,993 bytes gzip，英文 810,291 bytes gzip。
- 以 `python src/works/umbra-dial/render-posters.py --samples <目錄>` 離屏編譯及執行正式 WGSL，輸出三張食相與一張獨立社群封面，都是 1200 × 800 WebP。製作環境 wgpu 0.31.0、Pillow 12.0.0、GeForce RTX 3060／Vulkan。以同一組象牙色像素門檻檢視 GPU 時鐘 0、0.65、0.83、1.04、2.25、3 秒，其數量分別為 121,194、17,992、8,988、5,250、5,251、21,192，對應大弦月、窄弦月、亮珠、細光環、維持細光環及另一側復圓。0 與 10 秒的離屏影格逐像素相同。
- 兩語 DOM 模擬驗證正常排場、低於下限、非整數、兩種穹頂上下界、場地未確認、保留輸入回改、平均分場及 Blob 內容。最後一組改為大型穹頂 73 人和第三部片，三場為 25、24、24 人。繁中提案 589 bytes，英文 643 bytes。`flow.mjs` 提供隔離瀏覽器驗證所需的 `setMaterial` 與 `testFlow`。

## 手機暫停複合影像

針對整合候選 `6393cd7` 的 `pause-immediate.png` 與 `pause-after-1s.png` 比對 RGB。兩語取景皆為 352 × 235，且各自的裁切座標前後一致。繁中兩張開拍相差 1,425.9 ms，3,124 個變動像素全部在暫停按鈕矩形內（相對裁切左上角 x 267–337、y 13–56）。英文相差 1,410.9 ms，5,412 個變動像素也全部在按鈕內（x 215–337、y 13–56）。按鈕外的日輪、月影、日冕與背景逐像素相同。即時擷取的整個按鈕矩形短暫變暗，符合 Chromium 觸控反白。

停用暫停按鈕的觸控反白，繼續使用按鈕文字與鍵盤焦點框回饋狀態。兩語建置也已確認都指向有效的同源 64 × 64 PNG favicon。修正後的手機截圖仍待隔離瀏覽器重跑。
