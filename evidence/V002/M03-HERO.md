# V002 M03｜FORME 燭台光場

以單一不透明程序場景代替 M02 的照片疊光。畫面以真正有內孔的 3D 環體、圓角底座、凹口燭杯、未點燃的細燭及燭芯構成，底座坐落在同場景的地面。反射方向由表面的距離函數微分求得，移動燈的幾何同時用於金屬反射、牆地照度和地面陰影。鏡面保留窄亮邊，拉絲以同一件幾何上的細紋、較廣的反射和較低峰值呈現。輪廓附近以實際像素尺寸做 2 × 2 覆蓋採樣，底座陰影沿旋轉後的圓角矩形腳印收斂。螢幕寬度只改構圖與相機視角。渲染尺寸維持原比例，DPR 1 的 CSS 渲染尺寸上限為 780 × 500，成像填滿首屏。

以固定 Shaders 4.0.7 的 [defineShader/WGSL API](https://shaders.com/docs/primitives/define) 建立自訂場景。既有元件各自建立表面法線和環境；單一自訂場景才能讓三件接合零件與燈光、地面陰影和遮擋共用空間。沿用既有 standalone 封裝及 telemetry opt-out。

自動光源用單一可暫停的有效經過時間，在 12 秒內往返一次。光角滑桿切換固定光角，自動掃光可從控制列恢復。暫停保留上一個 WebGPU 畫面，並停止光角輸入；無 WebGPU、初始化失敗、減少動態或關閉 JS 則顯示對應表面的原始商品照。詢問清單、產品與價格不受光線控制影響。

驗證保留既有雙語商業流程及可及性。隔離 runner 另外擷取 1440/390 兩種視窗、雙表面的 0/2/4/6/8/10/12 秒 自然運作的原始 GPU 紋理並記錄請求時間，另保留 Chromium 可控時鐘下的逐時 GPU PNG 與循環閉合量測、五個固定角度、返回 0 度、暫停前後、續播、90 度 GPU 紋理與全頁畫面。作者測試與獨立動態貼合審查使用同一候選 SHA。
