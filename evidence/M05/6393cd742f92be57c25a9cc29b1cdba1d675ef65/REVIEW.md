# M05 第一次候選退修

固定來源 `6393cd742f92be57c25a9cc29b1cdba1d675ef65`。五件作品、兩個語言、兩種 viewport 的 20 個原始資料包均已產生。逐環境狀況見 [首輪結果](first-review.json) 與 [正式檢驗](https://github.com/KYStr/glossquote-visuals/actions/runs/44799612467)。

- 布邊的三種織法可辨。手機首三秒的緯線與底布顏色接近，需要更顯眼的穿梭及壓實，保留清楚的纖維。
- 果時桌面繁中、英文的更新間隔第 95 百分位分別為 86.7 與 90.1 ms，超過 50 ms 門檻。兩語兩種尺寸的手動挖取與重設已完成。首訪的高度變化需更容易察覺，維持完整果凍直到訪客挖取。繁中桌面無腳本的文件讀取有一次逾時。
- 疊印的手機色版已能辨認，但套色動作太靠近完成位置，即時色彩偏淡。加大錯位、縮短首輪對位時間，擴大深色交疊。
- 摺徑的船板鉸接、船體輪廓與真實遮擋成立。三件新作的自託管字型受到驗證器舊的目錄規則誤判；改用該候選 commit 的共用及作品目錄字型清單。
- 食刻的兩個手機暫停截圖存在差異，位於材質區右上角控制鍵；另需補兩語的作品 favicon。暫停比對維持逐像素驗證。
