# M05 冷啟動、效能與暫停複驗

主責查看了桌機與手機實際首訪的前三秒、控制序列及商品頁。布邊在較小畫面能看清楚一條銅紅緯線從左側穿過墨綠經紗並貼入布邊。疊印起初只有喇叭口與音箱一角相交，隨後喇叭覆上音箱的同心圓，中央出現大片深紫色。摺徑的硬板沿鉸線落下，食刻的弦月逐步變窄。果時可以從指定側挖出一勺，重設後恢復完整輪廓。

以下項目退修，維持原來的門檻。[原始工作紀錄](https://github.com/KYStr/glossquote-visuals/actions/runs/44801490500)

- 果時繁中手機首訪，主執行緒長工作約 4.85 秒，首三秒缺少可辨材質。實際載入另一組中文字型，預載的專用字體未套用。
- 果時桌機繁中與英文的暫停截圖不相同，英文的畫格提交間隔 p95 是 59.7 ms。疊印兩語桌機分別是 56.6 與 52.4 ms。上限皆為 50 ms。
- 食刻減少動態時，停用按鈕與背景實際對比約為 4.33:1。改用不透明色值並保留停用外觀。
- 食刻繁中桌面與手機約 2.98 秒的畫面仍是亮弦月。為兌現首三秒的細環與亮珠，縮短初次接近食甚的時間，保留後段慢速復圓。
- 現有 200% 縮放輸出雖有實際 DOM 尺寸，截圖右側遭裁切，需取得完整畫面才可判定版面。
