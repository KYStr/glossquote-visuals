## 人工覆核與簽認

五件作品的 UI-1、UI-2 均符合本批規則。依本候選的 50 張中英文原圖核對 320、390、768、1440 CSS px 與 200% 分頁縮放。各寬度的 CTA、商品規格、選項和結果都在欄內，沒有文字重疊、截字或水平溢出。10 張全頁縮放圖覆蓋 103 個 1440 × 900 的真實視窗，共 85,375 列。所有列與原始圖的像素相符。40 張常規圖片合計記錄 176 次來源圖片成功解碼，包含長頁下方的布樣、海報、收納箱與天文影片。

兩種語言的原生下拉都依閉合時顯示的初始值逐一覆核。布邊的布色 30/30、疊印的海報與紙材 30/30、摺徑的人數／航線／船型 30/30、蝕刻的影片與場地 20/20 均完整可讀。果時用按鈕選口味和數量。蝕刻英文 390 px 的影片欄由 151 px 加寬至 319 px，768 px 由 141 px 加寬至 299 px。本輪兩張原圖皆完整呈現 Chasing the Shadow。[兩處修改前後原尺寸對照](ui-V011-film-before-after.png) · [英文選單](ui-native-en.jpg) · [繁中選單](ui-native-zh-Hant.jpg)
