# 三件主視覺的實際操作

[查看桌機操作九格圖](HEROES.jpg)。各列依實際操作順序由左至右排列。完整逐幀圖、互動錄影和逐項判斷收在各作品的驗收紀錄。

- **果時**　我先看銀匙何時碰到果凍，再追蹤第二次挖取。匙面抬起後能同時看見橘瓣、左側原有的缺口與右側新切面。逆光保留了果肉輪廓。互動版匙上的果肉比核准圖更有稜角。[果時驗收](../../V008/df6ba61887571c76af1d2d65122db9905ba089bb/REVIEW.md)
- **疊印**　我對照了單藍、套到一半、雙色完成與單紅。印到一半時，刮刀後方出現朱紅字與網點，刀前的麥克風仍是藍色。完印後兩色交疊的深紫和右側錯位紅邊都留在紙上。[疊印驗收](../../V009/df6ba61887571c76af1d2d65122db9905ba089bb/REVIEW.md)
- **摺徑**　我沿著前甲板的黑繫繩追蹤包、半展折板和成艇三個階段。相連的板件先展長，側舷接著翻起。終態可以辨識完整艇身、座艙深度、椅背與貼水的下緣。互動版取景比核准圖寬一些。[摺徑驗收](../../V010/df6ba61887571c76af1d2d65122db9905ba089bb/REVIEW.md)

畫面來自固定版本的隔離 Windows Chromium 瀏覽器。桌機使用滑鼠，手機採觸控與窄視窗模擬。另有英文版、縮放、減少動態及繪圖不可用時的紀錄。[驗收執行紀錄](https://github.com/KYStr/glossquote-visuals/actions/runs/45002487345)
