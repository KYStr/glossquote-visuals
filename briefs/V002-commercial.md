# V002 流體檔案 — 金屬家飾品牌

主責分支 codex/v002-commercial，沿用 liquid-archive slug。品牌名選用「FORME 物形」，英文 FORME Objects。客戶是挑選家飾和空間陳設的設計愛好者。建立完整雙語商品網站，主行動為「探索系列」，商品行動為「加入詢問清單」。

## 美術與 UI

銀色金屬主商品為首屏核心，配合暖灰/深炭的空間與明確尺度。選三款可辨識的家飾，例如環形燭台、球形花器、弧形書擋，形體要有底座、厚度或接觸面，能理解用途。品牌名、產品名、短主張與主行動形成簡明層級，避免窄欄旁註包圍中間正方形。

主商品近景、整體造型、真實使用情境各有用途。優先生成原創的高品質產品情境圖（依 imagegen skill）並打包本地，禁止他牌圖、遠端嵌入或虛構製造認證。金屬高光要有細窄亮邊、暗面與曲率，避免大塊全白掩蓋表面。標題可以採俐落 grotesk，大幅留白和商品裁切建立辨識。中文正文需要一致、可讀字體。

使用 Chrome/實際 pinned shape API 組合讓反射與產品表面選項有關。可更換原 shader 組合。所有圖形須服務商品材質的呈現；一頁一個活動 canvas，原隱私和生命週期適用。

## 內容與流程

完整頁包括品牌與主商品首屏、三款系列、商品細節、材質/尺寸/保養、工藝介紹、交付與詢問 FAQ、詢問清單和品牌頁尾。每款有一致的名稱、用途、尺寸與示意價格，選擇亮面/霧面等表面處理會同步更新圖片/材質、商品資訊和摘要。

顧客可從商品卡選產品及表面、輸入數量、加入詢問清單，之後修改數量或移除、查看合計並下載完整詢問摘要。金額與數量必須一致。空清單、無效數量、加入回饋、鍵盤焦點、返回修改都可用。此流程全前端，完成提示是產生詢問摘要，無真實支付或寄送。

品牌為概念提案。頁尾清楚但克制標記「原創品牌網站概念，商品與售價為設計示意」。商品描述要像商家可用的文案，無假好評、假庫存緊迫、假售罄或客戶標誌。無 JS 可讀完整商品資料，合理提示互動清單的需求。
