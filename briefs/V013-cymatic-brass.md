# V013 · 銅頻 CYMATIC BRASS — 製作規格

## 1. 品牌定位與受眾
- **概念品牌**：銅頻 CYMATIC BRASS（聲學共振銅板與空間音景工坊）
- **目標客群**：建築室內設計師、錄音與聆聽空間規劃者、聲音藝術策展團隊。
- **核心任務**：讓訪客在首屏看見金屬銅板在特定頻率激振下，石英細砂離開反節點並匯聚成克拉尼（Chladni）幾何節線的物理過程；比較三款聲學銅板方案並匯出空間配置提案單。

## 2. 首屏物件、動作與美術細則（hero-craft-v1）
- **首訪可見物件**：架設於黑色消音工作台上的圓形拉絲黃銅共振盤、中央振子固定螺柱、外緣刻度環與盤面上的亮白石英細砂。
- **誰發起動作與前三秒表現**：首訪自動播放 12 秒循環；前 3 秒激振頻率由低頻掃入第一共振點，石英砂隨駐波振幅向外推擠並迅速收斂成清晰的四瓣、六星與蓮瓣節線圖形，每次共振定格停留供觀察。
- **桌機與手機辨識特徵**：深色實驗室儀表版型，搭配高對比等寬頻率數據（Hz）與節線模式切換器（288 Hz / 512 Hz / 768 Hz）；桌機與手機皆完整呈現銅盤圓形輪廓、中央螺柱與節線對比。
- **材質線索**：黃銅同心拉絲各向異性金屬高光 + 盤緣斜面倒角反光 + 細砂顆粒群集陰影。

## 3. 技術架構與降級
- **Shader**：`src/works/cymatic-brass/shader.js` + `chladni.wgsl`，透過 `initializeStandalone`（`disableTelemetry: true`）在單一 WebGPU canvas 執行。
- **降級**：同公式烘焙 `quad.webp`、`hex.webp`、`lotus.webp` 與 `cover.webp`；no-JS、WebGPU 失敗與減少動態時顯示對應頻率靜態共振圖，並可切換預覽與操作配置單。
- **生命週期**：使用 `createMotion` 與 `observeMotion`，提供暫停／繼續控制，離屏與背景分頁自動暫停。

## 4. 商業流程（BIZ-1 / BIZ-2）
- **三款聲學方案**：桌面共振盤 Desk Resonator（NT$ 14,800）、壁面擴散銅板 Wall Diffuser Panel（NT$ 32,000）、展演場域聲學矩陣 Spatial Array（NT$ 78,000），皆標明銅板厚度、適用面積、頻率特性與示意費用。
- **配置流程**：選擇方案、空間坪數/平方公尺、殘響取向、表面處理與組數，即時計算配置摘要並下載 `cymatic-brass-brief.txt`（標明概念品牌示意估算，無假送出）。
