# V003 夜航訊號 — 夜間音樂活動品牌

主責分支 codex/v003-commercial，沿用 night-signal slug。品牌「夜航訊號 NIGHT SIGNAL」，原創概念音樂活動。面向想了解演出並安排一晚行程的觀眾。完整雙語活動網站，主行動「查看票種」，以清楚資訊促成選場次和票種。

## 美術與 UI

首屏以大字、清晰有層次的波形/光束、節目時間和地點構成活動海報。原奶黃/午夜藍可保留，控制總體明暗節奏，讓低調背景襯托銳利的主形狀、光束與字。主視覺跨越版面，避免模糊波形被侷限在插圖框。頁面有海報首屏、緊湊時間表、較寬的場地內容和明確選票區，減少重複卡片與索引。

三個原頻道可轉為夜晚三個時段/節目。切換節目時更新節目資訊和視覺氣氛，讀者能看懂正在選什麼。日期與場地一律一致。使用原創藝名與場域概念，無真實演出者肖像或未授權商標。若加入場地/氛圍圖，用適切原創本地素材並記錄來源。

可重新組合免費 pinned Shaders 的 wave/grid/distortion/光場元件，形成乾淨的節奏和層次。字體在 HTML 保持清晰；動畫可暫停、無閃爍、一頁一 canvas、離開/隱藏停用。手機首屏顯示品牌、活動性質、示意時間地點和查看票種入口。

## 內容與流程

完整頁包含品牌活動首屏、三段節目與原創演出者介紹、時間表、場地/交通說明、兩至三種票、FAQ、選票流程和頁尾。資訊須自洽。每一票種差異與費用清楚，取消/入場說明標記為此概念提案的示意規則，不冒充真實承諾。

顧客能選票種和張數，立即看到票種差異、單價、總額、對應場次，返回修改，產生並下載行程/選票摘要。需有張數驗證、空選擇狀態、可讀錯誤、正確合計和完成回饋。結尾準確寫明「已產生選票摘要，尚未付款或保留席位」。禁止假出票、無效購票按鈕或只是改文案的表單。

原創品牌概念的揭露放頁尾與選票完成位置，日期/票價/場地是示意內容要一致標示。首屏文案仍像一個可提案給活動商家的成品。作品集與原始碼連結收於頁尾。無 JS 仍可查閱節目/票種等資料。
