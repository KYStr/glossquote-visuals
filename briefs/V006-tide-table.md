# V006 潮間帶 TIDE TABLE

## 對象與交付

海岸導覽概念品牌的完整繁中、英文商業網站。第一次想帶家人看潮池的人，能比較路線、步行距離、地形與裝備需求，帶走一份可用的出發清單。

## 首屏與版面

橫向海岸剖面。以深靛海水、礁岩米白、橙紅潮位尺交代水與陸。左下排大標，右方大幅潮池跨過中線。手機讓潮池完整占一個橫幅，再接路線入口。

原創地形高度場同時決定等高線、乾濕界線與泡沫邊緣。水位變化時低窪礁池先連通，三個潮位露出不同路徑。第一個自然週期直接示範一次漲落。用固定觀察範例說明潮位，清楚標為示意。

## 內容及客戶操作

選三條路線之一、同行人數、勾選裝備。切換路線會同步改變所需裝備和步行資訊。預覽並下載含路線、人數與自選裝備的行前單。無 JS 時可閱讀三條路線及列印基本清單。

## 此件美術驗收

潮位低／中／高及返回低點四張截圖。逐張核對兩處標記礁岩與一條水道，岸線沿等高線移動；漲潮不應淹沒高地卻留下低地乾燥。

## 製作約定

依 docs/M04-ACCEPTANCE.md 全項驗收與 AGENTS.md 邊界，沿用本機 vendored shaders skill、固定 standalone、雙語 metadata 與生命週期。使用原創在地素材，保留素材來源與可讀 DOM。主視覺和 fallback 共用構圖，降低動態預設靜止，能暫停與續播。檔案限定 works/tide-table、en/works/tide-table、src/works/tide-table、public/media/tide-table、evidence/V006。封面 public/media/tide-table/cover.webp，尺寸 1200×800；兩語頁要有完整 SEO 與可回畫廊入口。作者提供可執行商業流程測試（在作品 evidence 內）與候選 source；主責驗收整合。
