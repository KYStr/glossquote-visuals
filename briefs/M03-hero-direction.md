# M03 — 版頭的材質、空間與炫技

2026-11-13 使用者要求修正三件現有版頭並新增兩個主視覺，延續完整商業網站定位。主責美術指導、整合與發布；製作維持 gpt-6.1-sol/high。M02 已完成的分數是歷史，不視為使用者已接受本輪動態效果。

## 必要修正

### V001 紙與光

使用者觀察：動態開啟像把照片貼上去轉，關閉反而好看。來源為帶固定光影的照片加上平面 LinearGradient/Beam/Noise；沒有紙張曲面與壓紋法線，pause 又切換到不同 CSS 光照。

重做主視覺的材質與光照座標。優先以官方 Paper、Emboss、Surface3D/Form3D 等確切固定 API 建立可辨識的程序紙張、壓印和細纖維，或經審查的同座標 height/normal 模型。不得把帶烘焙光影的照片貼到旋轉平面當修好。光線掠過壓紋、邊緣、摺痕時須具有同一幾何邏輯；光影有層次，保留原靜態紙面的細膩。紙張可有克制的真實彎曲，不能廉價卡片旋轉。保留完整訂製流程、品牌與既有商品資訊。

### V002 FORME

使用者觀察：旋轉後有些反光像沒有貼在物體上。來源為 circleSDF 的圓盤法線，經 CSS 遮罩裁進環形燭台照片；照片原本的反射、光源與投影又沒同步。

反射必須由實際環體／商品幾何或嚴格對齊的 normal/height 表面決定，不可再以圓盤效果裁遮罩假裝 torus。優先將主商品與環境作為一致的程序場景處理，使用正確的 pinned 3D SDF/材質/環境參數；若保留攝影，須能證明局部表面、輪廓、內孔、接觸陰影在所有角度和尺寸均一致。移動光源和旋轉物件不可混稱，控制文案應符合真正行為。鏡面和拉絲均要有暗部、細紋、有限亮邊。保留已完成詢問清單。

### V003 夜航訊號

既有網站和選票流程可保留，但版頭要有更強的第一眼辨識與景深。提升為能傳達音樂現場的立體訊號雕塑／有前後層次的光帶或粒子結構；三場節目形成有意義的形態、節奏與色調變化。不可只加一層發光、提高速度或鋪更多模糊波形。大字與主視覺一起構圖，仍清楚顯示時間地點及主行動。禁止閃爍、聲音自動播放或控制搶奪捲動。

## 動態共同驗收

- 暫停必須凍結當前已呈現的合成畫面。不可把 canvas 隱藏、切回另一張更好看的 fallback，卻稱作暫停。初始化前或無 GPU 時保留設計完整的靜態 fallback；兩者清楚區分。
- 必須保存同一候選的實際連續動作證據：桌面／手機初始、自然運作至少 8 秒且至少五張原始影格，以 0/2/4/6/8 秒為採樣目標，另有控制最小／中間／最大、往返操作、暫停前／後／續播。逐張標記真正擷取時間或受控動畫時間；軟體 renderer 截圖延遲時不可把排程目標冒充實際時間。週期動畫覆蓋完整週期，短轉場需另取第一秒內的中間狀態。可加 WebM，但原始逐時影格不可省略；影片編碼 FPS 不等於實際渲染 FPS。
- reviewer 檢視紙面／輪廓／內孔／接觸面與材質是否固定在同一空間，無漂浮貼片、裁切、雙重高光或分離感。像素有變化僅能證明動態存在，不能代替此項美術驗收。
- 舊 native-pause 差異測試假設 pause 會移除 GPU，需要改為凍結穩定性。Shader 貢獻可在獨立診斷中暫時移除 canvas 作比較，但必須標明是診斷，不是產品操作。
- 保留原商業流程、雙語、320/390/768/1440、200%、鍵盤／觸控、no-JS/no-GPU/reduced-motion、hidden/offscreen、device recovery、同源隱私與一頁一 canvas。
- 每件美術／UI／商業完整度仍須各 >9/10，並增加上述連續動態貼合 gate。不得搬用 M02 的舊分數。
- 發布證據的 `temporalReview` 使用 `material-motion-v1`，綁定同候選與非作者 reviewer，記錄 desktop/mobile 的時間序列、控制與暫停前／立即／一秒後／續播影格及具體貼合判斷。週期動畫要覆蓋其完整週期；粒子等持續演化模擬記錄 `evolving`，不得捏造重複週期。發布程式會拒絕缺失時間影格、legacy-fallback 或不同候選的動態證據。

只使用現有 pinned shaders 4.0.7，先讀 vendored skill 與固定來源精確 props。官方預設登入／Pro／mutable npx 不適用。可使用自行託管、經查核的 ImageTexture/vector 資料，禁止遠端字型或 runtime CDN。自訂 shader 必須有具體必要性並遵循官方 custom shader API；不得自行換框架或加無關引擎。所有 browser 工作仍限定 GitHub-hosted 隔離 VM。

新作品見 V004-prism-materials.md、V005-aeriform.md。新製作承接紀錄先寫 coordination/m03-plan.json；runtime registry/catalog 由主責在各作者隔離 clone 作必要 seed，再由主責整合。正式網站在整批驗收前維持 M02。
